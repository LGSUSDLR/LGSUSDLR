### 📂 Proyectos Destacados

*   **MisVales:** Plataforma de gestión financiera multi-rol construida con Angular, Laravel, PostgreSQL, Redis y Docker, con autenticación segura vía Sanctum.
*   **Biblio-TK:** Sistema de gestión de biblioteca académica con captura automática de ISBN, credenciales digitales QR y sincronización offline.
*   **Dealer Management System (DMS):** Sistema integral para control de logística de importación, costos y ventas post-servicio automotriz.
*   **SIGAI:** Arquitectura para un Sistema Inteligente de Gestión Agrícola Integral.
